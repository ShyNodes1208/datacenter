# Phase 1: 平面图增强 — 设计规格

> 2026-07-28 | 参考 NetBox Floorplan Plugin / NetBox / Rackscope

## 背景

当前平面图已实现基础功能：机柜渲染、查看/编辑模式切换、拖拽移动机柜（含吸附对齐）、撤销重做、坐标持久化。但相比 NetBox Floorplan Plugin，缺少墙体绘制、区域划分、标签标注、SVG 导出和可视化放置机柜的能力。

## 目标

在现有 Konva 平面图基础上新增墙体/区域/标签元素，完善编辑工具栏，支持从机柜库拖入放置新机柜，并支持 SVG 导出。

---

## 1. 编辑工具面板

将当前两个模式切换按钮替换为编辑模式下的**竖向工具面板**，置于画布左侧。

### 工具列表

| 工具 | 图标 | 行为 |
|------|------|------|
| 选择/移动 | ↕ | 默认工具，点击选中元素，拖拽移动机柜 |
| 绘制墙体 | ╬ | 进入墙体绘制模式，mousedown 起点 → mousemove 预览 → mouseup 终点 |
| 放置机柜 | ⊞ | 打开右侧机柜库面板，拖入画布放置 |
| 添加标签 | T | 点击画布弹出输入框，输完文字后放置 |
| 添加区域 | ▢ | 拖拽绘制矩形区域（冷通道/热通道/功能区） |
| 删除 | ✕ | 点击画布元素确认删除 |
| 导出 SVG | ↓ | 将当前画布导出为 .svg 文件下载 |

底部常驻撤销/重做按钮。

### 查看模式

查看模式下工具面板隐藏，仅显示当前房间名称和"切换到编辑模式"按钮。

## 2. 新增数据模型

### 2.1 Wall（墙体）

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| RoomId | Guid | 所属机房，FK → Rooms |
| X1, Y1, X2, Y2 | double | 线段端点坐标（数据库坐标，mm） |
| Color | string | 颜色，默认 #333 |
| Thickness | int | 线宽，默认 3 |

### 2.2 Zone（区域）

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| RoomId | Guid | 所属机房，FK → Rooms |
| X, Y | double | 左上角坐标（数据库坐标，mm） |
| Width, Height | double | 宽高（数据库坐标，mm） |
| Name | string | 区域名称，如"冷通道-A" |
| Color | string | 填充颜色（半透明），默认 rgba(100,149,237,0.15) |
| ZoneType | string | 类型：cold-aisle / hot-aisle / functional / custom |

### 2.3 FloorplanLabel（标签）

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| RoomId | Guid | 所属机房，FK → Rooms |
| X, Y | double | 放置位置（数据库坐标，mm） |
| Text | string | 文字内容 |
| FontSize | int | 字号，默认 14 |
| Color | string | 文字颜色，默认 #666 |

### 2.4 后端 API

- `FloorplanController`，路由 `/api/rooms/{roomId}/floorplan-elements`
  - `GET` — 获取该机房所有墙体/区域/标签
  - `POST /walls` — 添加墙体
  - `PUT /walls/{id}` — 更新墙体
  - `DELETE /walls/{id}` — 删除墙体
  - 区域和标签同理

## 3. 机柜放置

### 3.1 机柜库面板

编辑模式下点击"放置机柜"工具，画布右侧弹出机柜库面板：

- 显示已有所有机柜列表（含 code、高度U、品牌）
- 每个机柜项可拖拽到画布上
- 拖到画布后：获取放置坐标 → 弹出快速编辑弹窗（code、高度U、品牌）→ 确认后调用 POST `/api/racks` 创建 → 画布渲染

### 3.2 已有：拖拽移动

当前拖拽移动机柜功能保持不变。

---

## 4. 交互详细

### 4.1 墙体绘制

1. 选中墙体工具
2. mousedown 在画布上 → 记录起点
3. mousemove → 实时预览线段
4. mouseup → 确认终点，调用 API 保存，画布渲染

### 4.2 区域绘制

1. 选中区域工具
2. mousedown → 记录起点
3. mousemove → 实时预览矩形
4. mouseup → 弹出名称/类型输入框 → 确认后调用 API 保存

### 4.3 标签添加

1. 选中标签工具
2. 点击画布位置 → 弹出输入框
3. 输入文字 → 确认后调用 API 保存

### 4.4 删除

1. 选中删除工具
2. 点击画布元素 → 弹出确认对话框
3. 确认 → 调用 API 删除 → 画布移除

### 4.5 选中 + 属性面板

选择模式 + 点击元素 → 右侧属性面板显示该元素属性（可编辑名称、颜色、尺寸等）。

---

## 5. SVG 导出

工具栏点击"导出 SVG"：

1. 遍历当前画布所有图层（墙体、区域、标签、机柜）
2. 用 Konva `stage.toDataURL()` 或手动构建 SVG 字符串
3. 触发浏览器下载，文件名 `{房间名}-平面图.svg`

## 8. 验收条件

1. 查看模式：只读查看平面图（墙体/区域/标签/机柜），滚轮缩放，拖拽平移
2. 编辑模式：工具面板显示，各工具可正常切换
3. 墙体绘制：可画直线段，颜色/粗细可调，可撤销
4. 区域绘制：可画矩形区域，命名，选择类型（冷/热通道）
5. 标签：可点击放置文字标注
6. 删除：可删除任意元素
7. 机柜放置：从库拖入新机柜，弹窗填写信息后创建
8. SVG 导出：导出完整平面图为 SVG 文件
9. 所有操作支持撤销/重做
10. 刷新页面后修改持久化
