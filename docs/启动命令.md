# 启动命令

> 所有命令从项目根目录 `/home/shy/projects/datacenter-layout` 执行。

## 前端

```bash
cd src/frontend
npm install          # 安装依赖（首次或 package.json 变更时）
npm run dev          # 启动 Vite 开发服务器
npm run build        # 生产构建
npm run typecheck    # TypeScript 类型检查
npm run test         # 运行 Vitest 测试
```

## 后端

```bash
# 首次运行先还原依赖
dotnet restore Datacenter.sln

# 启动 API 服务器
dotnet run --project src/backend/Datacenter.Api/
```

| 项目 | 地址 |
|------|------|
| API 服务 | <http://localhost:5142> |
| Swagger UI | <http://localhost:5142/swagger> |

### 数据库

- SQLite，文件路径：`src/backend/Datacenter.Api/.data/datacenter-dev.db`
- 默认管理员：`admin` / `admin123`
