## Windows 便携版 — 下载与安装

### 下载

| 项目 | 说明 |
| --- | --- |
| 安装包 | **[datacenter-2.0.5-win-x64.zip](https://github.com/ShyNodes1208/datacenter/releases/download/v2.0.5/datacenter-2.0.5-win-x64.zip)** |
| 类型 | 便携版（解压即用，**不是** `.msi` 安装程序） |
| 平台 | Windows 10 / 11，64 位 |

### 系统要求

- Windows 10 x64 或更高版本
- 任意现代浏览器（Edge / Chrome 等）
- **无需**安装 Node.js、.NET SDK 或 WSL（运行时已内置）

### 安装步骤

1. 从上方链接下载 `datacenter-2.0.5-win-x64.zip`。
2. 将压缩包解压到任意目录（**建议不要**放在 `C:\Program Files` 等需要管理员权限的路径）。
3. 进入解压后的 `datacenter-2.0.5-win-x64` 文件夹。
4. 双击 **`Start-Datacenter.bat`**。
5. 等待黑色命令行窗口出现「服务已启动」提示；浏览器会自动打开 **http://127.0.0.1:5142/**。
6. 若浏览器未自动打开，请手动访问上述地址。

### 首次登录

| 项目 | 值 |
| --- | --- |
| 用户名 | `admin` |
| 密码 | `admin123` |

> 首次登录后建议在系统中修改密码（当前版本为演示默认账号）。

### 停止服务

关闭 `Start-Datacenter.bat` 打开的黑色命令行窗口即可停止服务。

### 卸载

- 删除解压目录即可移除程序文件。
- 业务数据默认保留在 `%LocalAppData%\Datacenter\datacenter.db`；若需彻底清除数据，请同时删除该文件及所在文件夹。

### 数据存放位置

```
%LocalAppData%\Datacenter\datacenter.db
```

在资源管理器地址栏输入 `%LocalAppData%\Datacenter` 可快速打开。

## 导入自己的数据

首次启动数据库为空（仅含管理员账号）。压缩包内 **`import-templates`** 文件夹提供 Excel 导入模板：

| 模板文件 | 系统入口 |
| --- | --- |
| `机柜导入模板.xlsx` | 首页 → Excel 导入机柜 |
| `服务器导入模板.xlsx` | 首页 → 批量导入服务器 |
| `设备导入模板.xlsx` | 首页 → 批量导入设备；或机柜页 → 导入设备 |
| `线缆导入模板.xlsx` | 线缆管理 → 导入 Excel |

**方式 A — 一站式导入（推荐，v2.0.5 新增）**

若你已有「设备连接信息」整理合并格式的 Excel（每行一条线缆，含本端/对端机房、机柜、U 位、端口等）：

1. 首页 → **导入设备连接信息**
2. 上传 `.xlsx` → 预览统计与错误 → 确认导入
3. 系统自动创建机房、机柜、设备与线缆（无需分四步导入）

格式说明见压缩包内 `import-templates/导入文件格式说明.md` 第 5 节。空库下约 1800 行可在数秒内完成。

**方式 B — 分步模板导入**

1. 在首页 **手动新建机房**（分步导入时系统暂不支持机房 Excel 导入）。
2. 修改机柜模板中的「所在机房」为你的机房名称 → 导入机柜。
3. 修改服务器模板 → 批量导入服务器（可填写「所在机柜」和「起始 U 位」自动上架）。
4. （可选）导入设备 U 位标签，用于机柜正视图展示。
5. （可选）在线缆管理页导入线缆连接关系。

详细列格式见压缩包内 `import-templates/导入文件格式说明.md`，简要说明见 `import-templates/导入说明.txt`。

**注意：**

- 仅支持 `.xlsx` 格式，单文件不超过 10 MB。
- 请保留第 1 行表头，表头文字需与模板一致。
- 模板中的「示例机房」「A01」等仅为示例，请按实际情况修改。

## 常见问题

**Q：双击 bat 后窗口闪退？**  
A：确认解压完整、路径不含特殊字符；尝试以普通用户身份运行（无需管理员）。若端口 5142 被占用，关闭占用该端口的程序后重试。

**Q：浏览器显示无法连接？**  
A：确认命令行窗口仍在运行；等待数秒后刷新页面，或手动访问 http://127.0.0.1:5142/ 。

**Q：导入机柜提示「机房不存在」？**  
A：请先在首页创建与 Excel 中「所在机房」列完全一致的机房名称。

**Q：如何迁移到另一台电脑？**  
A：复制解压目录到新电脑；将 `%LocalAppData%\Datacenter\datacenter.db` 复制到新电脑相同路径即可保留数据。

## 本版本更新（v2.0.5）

- **新增**：首页「导入设备连接信息」— 支持整理合并格式 Excel 一站式导入机房、机柜、设备与线缆
- **新增**：导入前预览（行数、待创建资源、错误与警告）与确认后批量写入
- **说明**：重复导入已有数据时可能因 U 位占用而跳过部分线缆；全新空库可全量导入

## 本版本更新（v2.0.4）

- **修复**：中文 Windows 下 `Start-Datacenter.bat` / `Reset-Datacenter-Data.bat` 因 UTF-8 中文乱码无法执行（改为纯 ASCII 英文提示）

## 本版本更新（v2.0.3）

- **修复**：便携包中 `admin` 用户已存在但密码不是 `admin123` 时无法登录（启动时自动修复）
- **新增**：`Reset-Datacenter-Data.bat` 一键清空本地数据库（含解压目录与 `%LocalAppData%`）

## 本版本更新（v2.0.2）

- **修复**：Windows 便携包首次启动时 `admin` / `admin123` 无法登录（默认管理员未创建）
- **增强**：包内 `appsettings.Package.json` 内置管理员配置；`Start-Datacenter.bat` 等待服务就绪后再打开浏览器
- **说明**：若仍无法登录，删除 `%LocalAppData%\Datacenter` 后重新启动

## 本版本更新（v2.0.1）

- **修复**：全景线路图中选中设备后，拖拽平移或滚轮缩放不再丢失链接高亮
- **修复**：设备链接视图下点击具体线缆不再跳回全景，可查看右侧链路详情
- **增强**：Windows 便携包 `import-templates` 文件夹内置机柜/服务器/设备/线缆 Excel 模板

## 主要功能

- **机柜优先工作区**：单机柜成为设备查询与管理的默认入口
- **端口物理链路追踪**：支持已知目标最短路径与从端口发现可达终点
- **拓扑设备聚焦**：选中设备后显示物理可达子图并自动居中
- **机房平面图**：2D 平面图与线缆场景

## 技术栈

- 前端：Vue 3.5 + TypeScript + Konva 2.5D
- 后端：.NET 8 Web API + SQLite（自包含发布）
