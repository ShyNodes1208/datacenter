数据导入模板使用说明
====================

本文件夹提供 4 个 Excel 导入模板，配合系统内的导入功能使用。
详细列说明见同目录下的《导入文件格式说明.md》。

## 导入顺序（推荐）

1. 在首页手动新建机房（系统暂不支持机房 Excel 导入）。
2. 修改「机柜导入模板.xlsx」中的「所在机房」为你的机房名称，再导入机柜。
3. 修改「服务器导入模板.xlsx」后批量导入服务器（可顺带填写所在机柜和起始 U 位自动上架）。
4. （可选）修改「设备导入模板.xlsx」导入机柜 U 位标签，用于机柜正视图展示。
5. （可选）修改「线缆导入模板.xlsx」后在线缆管理页导入连接关系。

## 各模板对应入口

| 模板文件 | 系统入口 |
| --- | --- |
| 机柜导入模板.xlsx | 首页 → Excel 导入机柜 |
| 服务器导入模板.xlsx | 首页 → 批量导入服务器 |
| 设备导入模板.xlsx | 首页 → 批量导入设备；或机柜页 → 导入设备 |
| 线缆导入模板.xlsx | 线缆管理 → 导入 Excel |

## 注意事项

- 仅支持 .xlsx 格式，文件大小不超过 10 MB。
- 请保留第 1 行表头，表头文字需与模板一致。
- 模板中的「示例机房」「A01」等仅为示例，请按实际情况修改。
- 设备位导入会覆盖目标机柜现有的 U 位标签，不会创建服务器资产。
- 线缆导入要求源/目标设备已存在于系统中（可用服务器名称或管理 IP 匹配）。
