## §5 功能需求

### FR-VIS-01：层级切换器

页面顶部必须显示"机房级 / 机柜级 / 设备级"分段切换器。

1. 三个层级入口始终可见。
2. 当前层级必须有选中状态（主色描边 + 深色背景）。
3. 双击机柜进入设备级的行为必须保留。
4. 初次进入机房级时，必须显示可见文字："选择机房后查看机柜和设备链路"。
5. 从设备级返回机柜级或机房级时，当前机房上下文不得丢失。

### FR-VIS-02：深色主题

设备级画布必须使用拓扑页面专用的深色主题。

1. 主背景颜色固定为 `#071426`。
2. 第二背景颜色固定为 `#0B1B31`。
3. 网格线颜色固定为 `#5B7698`。
4. 网格线透明度固定为 `0.08`。
5. 网格必须使用斜向或透视网格。
6. 不得使用白色或浅灰色作为主画布背景。
7. 深色主题不得影响其他业务页面。

### FR-VIS-03：2.5D 地台

设备级画布必须绘制承载当前区域设备的 2.5D 地台。

1. 地台必须包含顶面、正面、右侧面、外边框、阴影、顶面透视网格和区域名称铭牌。
2. 地台不得只用一个矩形表示。
3. 顶面亮度最高；正面亮度低于顶面；右侧面亮度低于正面。
4. 阴影位于地台下方。
5. 区域铭牌位于地台正面中央。

### FR-VIS-04：2.5D 机柜

每个机柜必须表现为具有纵深的独立对象。

1. 每个机柜必须包含正面、顶面、右侧面、外边框、投影、机柜名称和内部设备安装区域。
2. 机柜不得只用一个 Konva.Rect 表示。
3. 顶面、正面和右侧面必须使用三个独立图形绘制，具有不同颜色。
4. 机柜右侧面必须产生可见纵深。
5. 机柜名称显示在机柜顶部。
6. 空机柜必须保留机柜外形，在设备安装区域显示"暂无设备"。
7. 机柜之间不得重叠；间距必须容纳线路和端口标签。

### FR-VIS-05：设备面板

设备必须绘制在所属机柜内部。

1. 每个设备必须显示设备名称、设备类型对应的面板外形、设备正面面板、面板边框、状态指示灯、端口锚点、选中状态和悬停状态。
2. 不得只通过矩形填充色区分设备类型。
3. 至少实现：服务器面板（含硬盘槽/散热孔和状态灯）、交换机面板（含连续端口阵列）、防火墙面板（含安全标识和网络端口）、存储设备面板（含磁盘槽阵列）、通用机架设备面板（含面板边框、状态灯和端口）。
4. 设备名称必须保持可读。
5. 设备数量超过机柜可视高度时，不得让设备相互覆盖。

### FR-VIS-06：端口锚点

线路必须连接到设备端口。

1. 每个参与连接的端口必须显示端口锚点、端口名称、端口状态和线路连接位置。
2. 端口锚点直径不得小于 8 个画布像素。
3. 被选中的端口锚点直径不得小于 12 个画布像素。
4. 端口标签不得覆盖设备名称。
5. 端口标签不得被设备面板裁切。
6. 线缆数据不存在端口信息时，显示"端口信息缺失"，不得把线路连接到设备中心伪装成有效端口连接。

### FR-VIS-07：线路颜色

所有设备线路必须按照线缆用途显示颜色。

| 用途 | 颜色 | 说明 |
|------|------|------|
| 管理网络 | `#39D9FF` | 映射 Purpose = 正常 或 CableType = 网线 |
| 业务网络 | `#9567FF` | 映射 Purpose = 上联 |
| 存储网络 | `#FFB341` | 映射 Purpose = 存储 |
| 告警/异常 | `#FF4D5A` | 映射设备 OperationalStatus = 异常 |

左下角图例必须显示以上颜色与名称。

**数据映射裁定：** 当前数据库 Cable.Purpose 值为 正常/上联/存储。CR-002 将 正常 映射为管理网络色 (`#39D9FF`)、上联 映射为业务网络色 (`#9567FF`)、存储 映射为存储网络色 (`#FFB341`)。告警状态来自 Server.OperationalStatus = 异常 的设备的关联线路。此映射为纯前端展示层映射，不新增数据库字段、不修改 API 响应、不伪造 Purpose 值。图例标签使用映射后的显示名称。

### FR-VIS-08：线路布局

1. 线路不得穿过设备面板。
2. 线路不得穿过机柜名称。
3. 线路不得穿过端口标签。
4. 线路必须经过机柜之间的走线区域。
5. 同一端口的多条线路必须产生可辨认的偏移。
6. 线路交叉点不得表现为连接节点。
7. 线路端点必须与端口锚点重合。

### FR-VIS-09：静态方向箭头

所有存在方向信息的线路必须始终显示静态方向箭头。

1. 静态箭头不依赖动画开关。
2. 静态箭头不依赖线路选中状态。
3. 单向线路只显示一个方向的箭头。
4. 双向线路显示两个方向的箭头。
5. 箭头颜色与线路颜色一致。
6. 箭头沿线路切线方向旋转。
7. 每条可见线路至少显示一个完整箭头。
8. 线路长度允许时，每隔 80 个画布像素显示一组箭头。
9. 缩放后箭头方向必须保持正确。
10. 开启 prefers-reduced-motion 后，静态箭头仍然显示。

### FR-VIS-10：线路选择和路径高亮

1. 选中线路宽度固定为 4 个画布像素。
2. 未选中线路透明度固定为 0.22。
3. 选中线路显示同色外发光，shadowBlur 固定为 12。
4. 源端口和目标端口同时高亮。
5. 源设备和目标设备边框同时高亮。
6. 右侧详情面板显示该线路。
7. 详情面板显示：起点设备名称、起点端口名称、终点设备名称、终点端口名称、线路类型、线路状态、带宽字段、单向/双向、所属机房、所属机柜、完整路径。
8. 没有实际带宽数据时显示"未配置"，不得生成虚假的带宽数值。
9. 再次点击画布空白区域后取消选择。
10. 取消选择后全部线路恢复原始透明度。
11. 高亮不能改变线路的业务类型颜色。

### FR-VIS-11：装饰性动画

1. 操作栏必须提供"流动动画"开关。
2. 动画开关默认关闭。
3. 用户选中线路并打开动画开关后，选中线路播放装饰性流动动画。
4. 动画使用移动虚线、移动光点或沿线路移动的箭头。
5. 动画周期固定为 1400ms。
6. 动画方向必须与线路方向一致。
7. 双向线路必须表现两个方向。
8. 切换选中线路后，旧线路动画立即停止，新线路开始动画。
9. 取消选中后，全部动画停止。
10. 页面切换、组件卸载和模式切换时必须停止 Konva.Animation 或 requestAnimationFrame。
11. 不得用动画速度、光点数量或颜色表达真实带宽、真实流量或设备负载。
12. 开启 prefers-reduced-motion 时，动画停止，静态箭头、选中高亮和详情面板仍然工作。

动画开关旁边必须固定显示"非实时流量"。

鼠标悬停或帮助提示必须显示："线路动画用于展示连接方向，不代表实时流量、带宽或设备负载。"

不得使用"实时流量""实时传输""实时速率"等文字描述装饰性动画。

### FR-VIS-12：筛选

至少支持按设备名称、设备类型、线路类型、线路状态筛选。

筛选后必须同时更新设备显示、线路显示、图例统计和当前选择状态。

被筛掉的线路如果处于选中状态，必须取消选择并关闭详情。

### FR-VIS-13：画布操作

1. 支持拖拽平移。
2. 支持鼠标滚轮缩放。
3. 缩放范围必须限制。
4. 提供"适应屏幕"按钮。
5. 窗口尺寸变化后重新适配。
6. 节点和线路不得被右侧详情面板遮挡。

### FR-VIS-14：面包屑和标题

1. 设备级页面顶部必须显示当前机房名称和区域名称。
2. 面包屑格式："机房拓扑 / 当前机房 / 当前区域 / 设备链路"。
3. 右侧详情面板显示完整端点路径。

### FR-VIS-15：性能与生命周期

1. 不得在 Vue 响应式更新中重复创建未销毁的 Konva Stage。
2. 模式切换时必须销毁旧节点、监听器和动画实例。
3. 组件卸载时必须销毁 Stage、Layer、Animation 和窗口监听器。
4. 同一条线路不得因响应式更新重复渲染。
5. 页面缩放和平移时不得重新请求后端数据。
6. 装饰性动画只能更新动画层，不得在每一帧重建全部设备节点。
